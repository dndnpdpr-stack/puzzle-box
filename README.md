## 마방진

가로·세로·대각선의 합이 모두 같아지도록 1부터 n²까지의 숫자를 한 번씩 채웁니다.

- 크기: 3×3 ~ 8×8
- 난이도: 쉬움(60% 공개) / 보통(45%) / 어려움(30%) / **1만 주기**(공식대로 만들 때 1이 놓이는 자리에 1만 표시)
- 가로·세로·대각선 합 실시간 표시, 중복 숫자 표시, 남은 숫자 목록, 타이머, 힌트, 정답 보기
- 정답 예시와 달라도 조건을 만족하면 성공으로 인정

### 공식

마법의 합: **S = n(n² + 1) / 2**

| 크기 | 방법 | 1의 위치 |
|---|---|---|
| 홀수 (3, 5, 7) | 시암 방법: 오른쪽 위로 한 칸씩, 막히면 바로 아래 | 맨 윗줄 가운데 |
| 4의 배수 (4, 8) | 1~n²을 차례로 쓰고, 4×4 블록 대각선 칸을 n²+1−v로 뒤집기 | 오른쪽 아래 모서리 |
| 4k+2 (6) | 스트레이치 방법: 홀수 마방진 4개를 사분면에 배치 후 일부 열 위·아래 맞바꾸기 | 맨 윗줄 두 번째 칸 |

무작위 문제는 공식 마방진에 회전·반사, 보수 변환(x → n²+1−x), 대칭 줄 쌍 섞기를 적용해 만듭니다.

## 기사의 여행

체스 나이트(L자 이동)로 판의 모든 칸을 정확히 한 번씩 밟습니다. 시작 칸으로 돌아올 필요는 없습니다.

- 크기: 5×5 ~ 8×8. 아무 칸이나 눌러 시작하거나 "무작위 시작"을 누릅니다. 5×5와 7×7은 일부 칸에서만 완주할 수 있어서, 안 되는 칸을 누르면 알려줍니다.
- 도움 표시를 켜면 다음에 갈 수 있는 칸이 강조됩니다.
- 버튼: 되돌리기, 다시 시작(같은 시작 칸에서), 힌트(끝까지 갈 수 있는 다음 칸), 새 게임
- 힌트는 Warnsdorff 순서(갈 곳이 적은 칸 먼저)로 탐색하는 백트래킹 풀이기가 찾습니다.

## 별 배치

n×n 판이 n개의 색깔 영역으로 나뉩니다. 가로줄, 세로줄, 색깔 영역마다 ★을 하나씩 놓고, ★끼리는 대각선을 포함해 이웃 8칸에 붙을 수 없습니다(장르 이름 Star Battle).

- 크기: 5×5 ~ 9×9
- 한 번 누르면 X, 두 번 빠르게 누르면 ★(다시 누르면 지움). 빈칸에서 끌면 지나가는 칸에 X, X에서 끌면 지나가는 X를 지움(★은 그대로). 정답 자리가 아니거나 규칙에 어긋난 ★은 빨간색으로 표시됩니다.
- 버튼: 되돌리기, 지우기, 힌트, 정답 보기, 새 게임
- 힌트는 정답 ★을 보여주지 않고, 지금 판에서 논리로 ★이 올 수 없는 칸을 찾아 X를 놓고 이유를 알려줍니다. 쉬운 추론부터 씁니다: ★ 주변 → 후보가 하나뿐인 줄·열·영역 → 한 줄에 갇힌 영역 → 다른 곳을 막는 칸 → 영역 k개가 줄 k개에 갇힌 경우. 틀린 ★이나 X가 있으면 먼저 짚어줍니다.
- 문제는 매번 새로 만들고 정답은 항상 하나입니다: 규칙에 맞는 별 배치를 무작위로 만들고, 각 별에서 영역을 키운 뒤, 정답이 둘 이상이면 다른 정답의 별 칸을 옆 영역으로 옮겨 그 정답을 없앱니다.

```
node --test
```

## 퍼즐 추가하기

폴더 하나(`<퍼즐>/index.html`, `../common.css` 사용, 상단에 `<a class="back" href="../">← 퍼즐 목록</a>`)를 만들고, 루트 `index.html`에 카드 하나를 더하면 됩니다.
