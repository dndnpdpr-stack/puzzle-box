# 마방진 퍼즐

브라우저에서 바로 하는 마방진(Magic Square) 퍼즐 게임과, 마방진을 만드는 공식을 단계별 애니메이션으로 보여주는 설명 페이지입니다.

## 바로 플레이

- 🎮 게임: https://dndnpdpr-stack.github.io/puzzle-box/
- 📖 만드는 법: https://dndnpdpr-stack.github.io/puzzle-box/guide.html

## 실행

설치할 것이 없습니다. 위 링크로 열거나, 내려받아서 `index.html`을 브라우저로 열면 됩니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 퍼즐 게임 |
| `guide.html` | 마방진 만드는 법 (단계별 애니메이션) |
| `magic.js` | 마방진 생성·검증 로직 |

## 게임

- 크기: 3×3 ~ 8×8
- 난이도: 쉬움(60% 공개) / 보통(45%) / 어려움(30%) / **1만 주기**(공식대로 만들 때 1이 놓이는 자리에 1만 표시)
- 가로·세로·대각선 합 실시간 표시, 중복 숫자 표시, 남은 숫자 목록, 타이머, 힌트, 정답 보기
- 정답 예시와 달라도 조건을 만족하면 성공으로 인정

## 공식

마법의 합: **S = n(n² + 1) / 2**

| 크기 | 방법 | 1의 위치 |
|---|---|---|
| 홀수 (3, 5, 7) | 시암 방법: 오른쪽 위로 한 칸씩, 막히면 바로 아래 | 맨 윗줄 가운데 |
| 4의 배수 (4, 8) | 1~n²을 차례로 쓰고, 4×4 블록 대각선 칸을 n²+1−v로 뒤집기 | 오른쪽 아래 모서리 |
| 4k+2 (6) | 스트레이치 방법: 홀수 마방진 4개를 사분면에 배치 후 일부 열 위·아래 맞바꾸기 | 맨 윗줄 두 번째 칸 |

무작위 문제는 공식 마방진에 회전·반사, 보수 변환(x → n²+1−x), 대칭 줄 쌍 섞기를 적용해 만듭니다.
